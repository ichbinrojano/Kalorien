# Kalorien

Minimalistischer, kostenloser Kalorien- und Nährstoff-Tracker als Web-App.

- Tagesübersicht mit Kalorien, Protein, Fett, Kohlenhydraten und Mikronährstoffen
- Eingebaute Basis-Lebensmittel + Produktsuche über Open Food Facts
- Live-Barcode-Scanner
- Gespeicherte Mahlzeiten
- Läuft offline, Daten bleiben auf dem Gerät (Backup-Funktion in den Einstellungen)

**Installieren am iPhone:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Produktdaten: [Open Food Facts](https://openfoodfacts.org) (ODbL).
